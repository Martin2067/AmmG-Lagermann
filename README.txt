AmmG – nový statický web

Soubory:
- index.html
- style.css
- script.js
- contact.php
- img/

Lokální náhled:
Otevřete index.html nebo spusťte jednoduchý lokální server.

Nasazení:
Nahrajte obsah složky do kořenové složky webu. Před nasazením zálohujte stávající web.

Poznámka:
Zkontrolujte cílový e-mail v contact.php a otestujte odeslání formuláře na hostingu s PHP.
